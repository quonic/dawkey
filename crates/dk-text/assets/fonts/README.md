# Fonts

Noto Sans (Regular, SemiBold) and Noto Sans Mono (Regular), version 20251201,
copied from Fedora's `google-noto-sans-fonts` and `google-noto-sans-mono-fonts`
packages. Licensed under the SIL Open Font License 1.1 (see `OFL.txt`).

They are embedded in the binary so text renders identically everywhere,
which the screenshot tests rely on.
