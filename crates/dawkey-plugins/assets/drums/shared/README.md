# Shared samples

`clap.flac`: `Idiophones/Struck Idiophones/Claps/SoloClap_vl3.wav` from the
[Versilian Community Sample Library](https://github.com/sgossner/VCSL)
(CC0; see `CC0.txt`). A single real hand-clap, downmixed to mono. Shared
(via a `const`, not a second `include_bytes!`) by every VCSL-sourced kit
that wants a real Clap pad instead of leaving it synthesized.
