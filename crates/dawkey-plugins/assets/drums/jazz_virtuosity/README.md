# Jazz (Virtuosity) sample kit

Seven one-shot hits from [Virtuosity Drums](https://versilian-studios.com/virtuosity-drums/)
by Versilian Studios, via its [CC0 GitHub mirror](
https://github.com/sfzinstruments/virtuosity_drums). A jazz kit played
with sticks, miked at the "mid" (overall) position. Downmixed to mono;
the three cymbals were trimmed to 2.5s with a short fade-out (the source
recordings ring for several more seconds). No other processing.

| Pad | Source file (`Samples/mid/...`) |
|---|---|
| Kick | `kick/mid_kick_snoff_vl3_rr1.flac` (snares off, so it's an isolated kick, not a kit ambience bleed) |
| Snare | `snare/mid_snare_center_vl6.flac` |
| Closed Hat | `hh/mid_hh_closed_vl2_rr1.flac` |
| Open Hat | `hh/mid_hh_open_vl2_rr1.flac` |
| Tom | `htom/mid_htom_center_vl8.flac` |
| Crash | `crash/mid_crash_crash_vl2_rr1.flac` |
| Ride | `ride/mid_ride_ride_vl2_rr1.flac` |

Unlike the `acoustic_vcsl` kit, this one has a real ride and no missing
instruments — every pad but Clap has a sample (Virtuosity Drums has no
hand-clap either, so Clap still synthesizes).

Licensed CC0 1.0 Universal (see `CC0.txt`).

Embedded in the binary so sample playback works identically everywhere, the
same reason `dawkey-text` embeds its fonts.
