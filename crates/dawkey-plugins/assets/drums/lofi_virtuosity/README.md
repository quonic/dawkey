# LoFi sample kit

The exact same performance and pad choices as the `jazz_virtuosity` kit,
from [Virtuosity Drums](https://versilian-studios.com/virtuosity-drums/)'
[CC0 GitHub mirror](https://github.com/sfzinstruments/virtuosity_drums) —
but miked at its "lofi" position instead of "mid", a deliberately
degraded, filtered, lower-fidelity sound the library ships as its own
alternate mic. Downmixed to mono; the three cymbals were trimmed to 2.5s
with a short fade-out, same as the other Virtuosity-sourced kit.

| Pad | Source file (`Samples/lofi/...`) |
|---|---|
| Kick | `kick/lofi_kick_snoff_vl3_rr1.flac` |
| Snare | `snare/lofi_snare_center_vl6.flac` |
| Closed Hat | `hh/lofi_hh_closed_vl2_rr1.flac` |
| Open Hat | `hh/lofi_hh_open_vl2_rr1.flac` |
| Tom | `htom/lofi_htom_center_vl8.flac` |
| Crash | `crash/lofi_crash_crash_vl2_rr1.flac` |
| Ride | `ride/lofi_ride_ride_vl2_rr1.flac` |

Like `jazz_virtuosity`, Clap has no source here and keeps synthesizing.
