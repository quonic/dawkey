# Acoustic (VCSL) sample kit

Seven one-shot hits from the [Versilian Community Sample Library](
https://github.com/sgossner/VCSL), a CC0 (public-domain) sample library.
Downmixed to mono; the three cymbals were trimmed to 2.5s with a short
fade-out (the source recordings ring for several more seconds). No other
processing.

| Pad | Source file |
|---|---|
| Kick | `Membranophones/Struck Membranophones/Bass Drum 1/BDrumNew_hit_v2_rr1_Sum.wav` |
| Snare | `Membranophones/Struck Membranophones/Snare Drum, Modern 1/Snare2_HitNS_v4_rr1_Mid.wav` |
| Closed Hat | `Idiophones/Struck Idiophones/Hi-Hat Cymbal/HiHat_Close_rr1_Mid.wav` |
| Open Hat | `Idiophones/Struck Idiophones/Hi-Hat Cymbal/HiHat_HitO_rr1_Mid.wav` |
| Tom | `Membranophones/Struck Membranophones/Tom 1/Stick/TomH_HitS_v3_rr1_Mid.wav` |
| Crash | `Idiophones/Struck Idiophones/Clash Cymbals 1/cymbal_crash1_mf1.wav` |
| Ride | `Idiophones/Struck Idiophones/Suspended Cymbal 1/susCymb1_hit_stick_mp1.wav` |
| Clap | `Idiophones/Struck Idiophones/Claps/SoloClap_vl3.wav` (in `assets/drums/shared/`, reused by other kits) |

VCSL has no dedicated ride cymbal instrument, so Ride uses a stick-struck
suspended cymbal in its place.

Licensed CC0 1.0 Universal (see `CC0.txt`): "Essentially it's Public Domain -
you can do whatever you want with these sounds (even make commercial
software), no royalties, no credit, no special terms."

Embedded in the binary so sample playback works identically everywhere, the
same reason `dawkey-text` embeds its fonts.
